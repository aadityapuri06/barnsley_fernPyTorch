# barnsley_fernPyTorch

Generate the classic [Barnsley fern](https://en.wikipedia.org/wiki/Barnsley_fern) fractal using a vectorized, GPU-capable implementation in PyTorch. Instead of iterating one point at a time, `n_points` points are evolved in parallel across `n_iterations` steps of the chaos game, using tensor ops that run on either CPU or CUDA.

## How it works

The Barnsley fern is generated by an [iterated function system](https://en.wikipedia.org/wiki/Iterated_function_system) (IFS) made of 4 affine transformations. At each step, every point independently and randomly picks one of the 4 rules (weighted by its selection probability) and maps `(x, y) -> (a*x + b*y + e, c*x + d*y + f)`:

| Rule | a     | b     | c     | d    | e | f    | Probability | Effect                        |
|------|-------|-------|-------|------|---|------|-------------|--------------------------------|
| f1   | 0.00  | 0.00  | 0.00  | 0.16 | 0 | 0.00 | 0.01        | Stem                           |
| f2   | 0.85  | 0.04  | -0.04 | 0.85 | 0 | 1.60 | 0.85        | Successively smaller leaflets  |
| f3   | 0.20  | -0.26 | 0.23  | 0.22 | 0 | 1.60 | 0.07        | Largest left-hand leaflet      |
| f4   | -0.15 | 0.28  | 0.26  | 0.24 | 0 | 0.44 | 0.07        | Largest right-hand leaflet     |

## Notebook walkthrough (`barnsley_fern.ipynb`)

1. **Setup** — import `torch`/`numpy` and select `device` (`cuda` if available, else `cpu`).
2. **Parameters** — `n_points = 100000` starting points, run for `n_iterations = 50` steps.
3. **Transformation rules** — the 4 rules above stored as PyTorch tensors: `coeffs` (shape `(4, 6)`, one `[a, b, c, d, e, f]` row per rule) and `probabilities` (shape `(4,)`), both on `device`.
4. **State tensors** — `points`: shape `(n_points, 2)`, all initialized to the origin `(0, 0)`; `history`: shape `(n_iterations, n_points, 2)`, which records every point's position at every iteration.
5. **Main loop** — for each iteration, every point independently samples a rule via `torch.multinomial(probabilities, ...)`, gathers that rule's coefficients, and applies the affine transform to all `n_points` points at once (fully vectorized, no per-point Python loop). Results are written into `history`.
6. **Plot** — all accumulated points across every iteration are flattened into one point cloud and rendered as a small green scatter plot (`figsize=(8, 10)`, no axis lines) to reveal the fern shape.

- Python 3

Prompt 1
--------
"add a new cell in barnsley_fern.ipynb defining n_points=100000 and
n_iterations=50 as different variables, add a new cell and define the 4
classic Barnsley affine tranformation rule as Pytorch tensors, their
coefficients and their selection probability"

Response:
- Read the existing notebook (which had cells for checking the Python
  executable, importing torch/numpy, and selecting the device).
- Added a new cell defining:
      n_points = 100000
      n_iterations = 50
- Added another new cell defining the 4 classic Barnsley fern affine
  transformations as PyTorch tensors:
      coeffs        -> shape (4, 6), rows = [a, b, c, d, e, f] for each
                        transform, mapping (x, y) -> (a*x + b*y + e,
                        c*x + d*y + f)
      probabilities -> shape (4,), values [0.01, 0.85, 0.07, 0.07]
  Both tensors were created on `device`.

Response:

      history -> shape (n_iterations, n_points, 2), zero-initialized on
                 `device`, to store every point's position at every
                 iteration for the final plot.


Prompt 3
--------
"add a new cell, write a main iteration loop: for each of iterations steps,
each point independently and randomly select one of the 4 rules, applies the
rule's transformation, and the new positions are stored"

Response:
- Added the main iteration loop cell. For each of the n_iterations steps:
    1. Sampled a rule index per point via
       torch.multinomial(probabilities, n_points, replacement=True), so
       each point independently and randomly picks one of the 4 rules
       weighted by their selection probability.
    2. Gathered each point's chosen [a, b, c, d, e, f] coefficients via
       coeffs[rule_idx].
    3. Applied the affine transform (x, y) -> (a*x + b*y + e, c*x + d*y + f)
       to all points in parallel (fully vectorized across n_points, no
       per-point Python loop).
    4. Stored the updated positions into history[i].
